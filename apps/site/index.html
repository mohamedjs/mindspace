MindSpace بيحوّل اللي بتكتبه أو بتقوله لـ sticky notes مترتبة على canvas: أفكار، وتاسكات بمواعيد، وأسئلة، وكل نوتة متوصلة بأصلها. ومتوصل بـ Claude عن طريق MCP، فـ Claude يقدر يبني بوردك ويقراه بنفسه.

دقيقتين: الشات في الموقع، و Claude بيبني بورد كامل عن طريق MCP، والـ views، والإعدادات. كل اللي في الفيديو متصوّر من الأبلكيشن الحقيقي.

كل اللي محتاجه عشان أفكارك ماتضيعش

اكتب أو اتكلم

قول الفكرة زي ما هي، عربي أو إنجليزي. الـ AI بيقسمها لنوتس لوحده: فكرة، وتاسك، وسؤال، وقرار.

أربع طرق تشوف بيها

نفس النوتس على Canvas تحركها بإيدك، أو Mind Map، أو List، أو Calendar.

بيفهم المواعيد

«بكرة الصبح» أو «السبت» بتتحول لميعاد على النوتة، وتلاقيها في الـ Calendar، ويوصلك تذكير قبلها.

متوصل بـ Claude

عن طريق MCP: اطلب من Claude يعمل خطة أو يرتب أفكارك، وهو يبني البورد بنفسه في خطوة واحدة.

اختار الموديل

في الخطط المدفوعة تختار أي موديل من OpenRouter للكتابة وللفويس.

من الموبايل كمان

نفس الأبلكيشن في متصفح الموبايل، بشكل مظبوط على الشاشة الصغيرة.

وصّل Claude في تلات خطوات

Claude هو اللي بيفكر ويكتب النوتس، فمش بيتخصم أي credits من رصيدك في MindSpace.

  1. 1

    اعمل token

    من الإعدادات، جزء Connect AI assistants، اضغط Create token.

  2. 2

    انسخ الإعدادات

    الصفحة بتديك الإعدادات جاهزة لـ Claude Code و Claude Desktop و Cursor.

  3. 3

    اطلب اللي عايزه

    «اعمل لي خطة لفتح البيكري» أو «إيه اللي لازم أخلصه الأسبوع ده؟». Claude يقرا ويكتب في بوردك.

Claude Code 
claude mcp add --transport http mindspace https://<your-mindspace>/mcp \
  --header "Authorization: Bearer <your token>"
إنت Claude سيرفر MCP MindSpace API بوردك

أسئلة

بيفهم العامية المصري؟

أيوه. تقدر تكتب أو تتكلم بالعامية أو بالإنجليزي أو الاتنين مع بعض، والنوتس بتطلع باللغة اللي اتكلمت بيها.

Claude بيصرف من الـ credits بتوعي؟

لأ. لما Claude يكتب عن طريق MCP، النوتس بتتحفظ زي ما بعتها، من غير ما MindSpace يشغّل الـ AI بتاعه.

أوصّل أنهي assistants؟

أي حاجة بتدعم MCP عن طريق HTTP، زي Claude Code و Claude Desktop و Cursor. صفحة الإعدادات بتديك الإعدادات جاهزة للنسخ.

الـ token يقدر يعمل إيه؟

يقرا ويكتب في الـ spaces والنوتس بس. مايقدرش يغيّر حسابك ولا الدفع ولا مفاتيحك، وتقدر تلغيه في أي وقت.
