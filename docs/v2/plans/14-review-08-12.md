## Review notes

### 08 web
- **Defects:** content update used the wrong URL; payment providers not unwrapped; BYOK save sent empty `baseUrl`; recording create dropped `parent_note_id`/`target_note_id`; SSE never reconnected and skipped 401 refresh; no fail-closed entitlements or literal-named feature flags; `/record` not gated; swallowed `finishRecording` errors; group frame ignored note size; group undo read a stale closure; shortcuts hard-coded instead of `CANVAS_TOOLS`; single-note mutations missing in-place cache updates.
- **Fixes/tests:** `api.test.ts` (URLs, unwrap, baseUrl, parent/target ids, single-flight refresh, SSE reconnect), `graph.test.ts` (18 cases), shortcuts test. 129 tests, tsc clean.
- **Human:** UI not clicked through (no browser by rule).

### 09 extension
- **Defects:** `isProcessing` early-return dropped parts under concurrent `PART_READY`/finish; no 401 refresh on start; failed finish discarded the active recording; browser restart with 0 pending parts never finalized; popup opened wrong space URL and ignored an empty access token after restart.
- **Fixes/tests:** serialized upload loop, `authedFetch`, kept state on failure, popup refresh. Two new tests in `uploader.test.ts`. 31 tests, zip builds.
- **Human:** real meeting capture (Meet/Zoom/Teams).

### 10 mobile
- **Defects:** same API-contract bugs as web (content URL, providers, `baseUrl`, parent/target ids); refresh token not restored from SecureStore on init; full `['notes']` invalidation on every mutation; group created without size; group undo deleted `groups[last]` (stale); Connect mode dropped back to pan after one link.
- **Fixes/tests:** new `api.test.ts` (init restore, single-flight refresh, content URL, providers, baseUrl omitted, recording ids, `/ai/*` mapping); targeted cache updates + bulk hooks; `gestureOrder.test.ts` still passes. 147 tests, tsc clean.
- **Human:** device run (gestures, mic, SecureStore on real hardware); `EXPO_PUBLIC_API_URL` per EAS profile.

### 11 landing
- **Defects:** empty links lost the "Coming soon" badge (queried the detached element); 4th pricing principle missing; GitHub link pointed at a non-existent org.
- **Fixes:** `updateLinksUI` badges the live element; `rule4*` EN/AR added; link corrected. Build + link checker pass.
- **Human:** copy/legal review; real store links.

### 12 hardening
- **Defects:** `restore.sh` swallowed every `pg_restore` failure (`|| true`) and overwrote the source DB when `TARGET_DB` was set; audio archive nested an extra directory so restore landed in the wrong path; prod Compose fell back to password `mindspace`.
- **Fixes/tests:** failing restore now exits non-zero; `TARGET_DB` created and used; audio archived from directory root; `--no-owner --no-privileges`; `POSTGRES_PASSWORD` required. New `backup-restore.test.ts` (caught a `sed` bug in my first fix; skipped where bash is absent, e.g. alpine dev image). A real round-trip against dev Postgres restored all 23 tables and the audio file.
- **Verified by reading:** Caddy `flush_interval -1` covers `/recordings*` (SSE route); API and web images run as `USER node`; runner image installs `curl` for the healthcheck.
- **Human:** actual deploy, SSE through Caddy with a real client.
